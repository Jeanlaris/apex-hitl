## Reporting a Vulnerability

We take the security of our sovereign ecosystem and software supply chain very seriously. If you discover a security vulnerability within any repository under our organization, please do not disclose it publicly through standard GitHub issues or discussions.

Instead, report it privately to ensure a controlled and secure remediation process:

- **Private Disclosure:** Send details directly to our security contact channel or open a private advisory via GitHub Security Advisories if available on the repository.
- **What to Include:** Please provide a detailed summary of the vulnerability, steps to reproduce, and potential impact.
- **Response Timeline:** We commit to acknowledging receipt of your report promptly and working collaboratively on a coordinated patch before any public disclosure.

Thank you for helping keep the architecture secure and resilient.
